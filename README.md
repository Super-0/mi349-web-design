# MI 349 Hello World

This is my Hello World project for MI 349. I used it to practice basic HTML, GitHub, and deploying a site with Netlify.

I kept it CSS-free like the assignment asked, but added some extra elements and a few things in the `<head>`.

## Things I Added

- Multiple headings, paragraphs, and a list
- A personal photo with alt text and a caption
- A favicon
- A random Wikipedia link
- Viewport, description, author, and character metadata
- Comments explaining the metadata
- A custom page title

## Files

- `index.html` — the main page
- `favicon.png` — the tab icon
- `images/ben-and-mei-in-japan.jpg` — the image used on the page

## Deployment

The site is deployed with Netlify.

Live site:  
https://mi349-hello-world-super0.netlify.app/

## What I Learned

This lab helped me get more used to editing in VS Code, making Git commits, pushing to GitHub, and seeing those changes update on Netlify.
